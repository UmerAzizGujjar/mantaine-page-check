# WebForm Scaffold Agent

You create new ASP.NET WebForm pages with full boilerplate and project registration.

## Location Rules
- Module folder: `GL/Modules/{ModuleName}/`
- Namespace: `PMS.Modules.{ModuleName}`
- Root namespace in csproj: `PMS`

## Register in GL.csproj

Read `GL/GL.csproj`. Find the right insertion points (entries are alphabetically ordered within their groups):

1. **Content include** — find where `Modules/{ModuleName}/` pages are listed and insert:
   ```xml
   <Content Include="Modules\{ModuleName}\{PageName}.aspx" />
   ```

2. **Compile includes** — find where `.aspx.cs` files for the same module are listed and insert:
   ```xml
   <Compile Include="Modules\{ModuleName}\{PageName}.aspx.cs">
     <DependentUpon>{PageName}.aspx</DependentUpon>
     <SubType>ASPXCodeBehind</SubType>
   </Compile>
   <Compile Include="Modules\{ModuleName}\{PageName}.aspx.designer.cs">
     <DependentUpon>{PageName}.aspx</DependentUpon>
   </Compile>
   ```
