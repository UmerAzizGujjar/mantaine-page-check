# Theme Primary Colors Reference

When updating CSS files (`CustomCSS/*.css`) across multiple themes, map the primary color to these hex values:

| Theme | Primary Color | Hex |
|-------|--------------|-----|
| `THEME_TIBBIT` | Gold | `#EFA63E` |
| `THEME_ASSIRAAT` | Green | `#308665` |
| `THEME_PAKRED` | Red | `#c11718` |
| `THEME_STANDARD` | Blue | `#438eb9` |
| `THEME_KHURSHID` | Red | `#c11718` |
| `THEME_NOOR` | Blue | `#438eb9` |
| `THEME_SKINSTUDIO` | Green | `#308665` |
| `THEME_KALEEM` | Green | `#308665` |
| `THEME_DEMO` | Green | `#308665` |
| `THEME_IITH` | Blue | `#438eb9` |
| `THEME_CPTH` | Red | `#c11718` |
| `THEME_NHMC` | Green | `#308665` |

## Gradient / Hover Mapping

For each primary color, use these derived values:

- **Gold** (`#EFA63E`): hover `#cb8d35`, gradient `135deg #EFA63E → #cb8d35`
- **Green** (`#308665`): hover `#256b50`, gradient `135deg #308665 → #256b50`
- **Red** (`#c11718`): hover `#9e1213`, gradient `135deg #c11718 → #9e1213`
- **Blue** (`#438eb9`): hover `#367498`, gradient `135deg #438eb9 → #367498`
